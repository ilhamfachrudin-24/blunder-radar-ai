# Contributing to Blunder Radar AI

Thank you for your interest in contributing to Blunder Radar AI.

This project is an AI-powered Solana intelligence platform focused on token analysis, smart money tracking, and Web3 research.

---

## How to Contribute

### 1. Fork Repository

Create your own fork of this repository.

---

### 2. Create a Branch

Use a descriptive branch name:

feature/new-analysis
bugfix/security-fix

---

### 3. Make Changes

Follow these guidelines:

- Keep code clean and readable
- Use TypeScript best practices
- Avoid exposing API keys
- Add comments for complex logic

---

## Development Setup

Install dependencies:

```bash
npm install

Run development server:

npm run dev

Pull Request Guidelines

Before submitting a pull request:

Test your changes
Explain what was changed
Keep commits clear
Security

Never commit:

API keys
Private keys
Wallet seed phrases
Personal credentials

Use environment variables instead.

Community

Suggestions and improvements are welcome.
